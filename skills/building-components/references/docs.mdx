## Essential Documentation Sections

### Overview
Brief introduction explaining what the component does and when to use it.

### Demo, Source Code, and Preview
Include a demo showing the component in action, plus the code used to create it.

### Installation
Clear single-command installation instruction:

```bash
npx shadcn@latest add <your-component-url>
```

### Features
List key capabilities: Customizable, Accessible, Composable, Type-safe, Theming support, Lightweight, SSR/SSG ready.

### Examples
Demonstrate flexibility with: Variants, States, Advanced Usage, Composition, Responsive Behavior.

### Props and API Reference
For each prop document: Name, Type, Default, Required, Description.

### Accessibility
Document: Keyboard navigation patterns, ARIA attributes, Screen reader support, Focus management.

### Changelog
Maintain version history with: New features, Bug fixes, Breaking changes, Migration guides.

## Best Practices

- Keep documentation up-to-date with code changes
- Use real-world examples
- Include common pitfalls and troubleshooting
- Provide performance considerations
- Link to related components and patterns
- Make all code examples runnable and tested
