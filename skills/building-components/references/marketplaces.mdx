Component marketplaces are centralized hubs where creators can publish components and consumers can discover, preview, and install them.

## How Marketplaces Work

1. **Hosts component code** - No infrastructure management needed
2. **Provides a unified CLI** - Standard installation commands
3. **Generates previews** - Live demos created automatically
4. **Handles discovery** - Search, categories, and recommendations

```bash
npx shadcn@latest add https://21st.dev/r/haydenbleasel/dialog-stack
```

## Benefits

### For Authors
- Distribution without infrastructure
- Built-in audience
- Monetization opportunities
- Community feedback loop

### For Consumers
- Curated discovery by category
- Quality assurance through review processes
- Unified tooling across all marketplace components
- Full source code ownership

## Challenges

- Competition and visibility in crowded marketplaces
- Platform dependency risk
- Variable quality despite review processes
- Discovery paradox (too much choice)
